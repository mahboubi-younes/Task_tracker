# Mon Assistant - Gestionnaire de Tâches

Mon Assistant est une application de bureau gratuite et 100% hors-ligne développée en Python avec le framework Qt. Elle permet de gérer vos tâches quotidiennes, de planifier vos objectifs avec un calendrier interactif et de recevoir des rappels automatiques en arrière-plan.

L'application intègre une couche de compatibilité dynamique lui permettant d'exécuter nativement Qt6 (PySide6) sous Windows 10/11 et Qt5 (PyQt5) sous Windows 7.

### Fonctionnalités

- Tableau de bord avec indicateurs de productivité et suivi des tâches urgentes
- Notification en arrière-plan intégrée à la barre des tâches Windows
- Vue calendrier mensuelle avec classement par priorité
- Compatibilité native Windows 7, Windows 10 et Windows 11
- Stockage local des données via SQLite, 100% confidentiel
- Thème sombre et raccourcis clavier
