Fonctionnalités Clés

Conçu pour une productivité personnelle optimale et réactive

📊

Tableau de Bord KPI

Suivez vos statistiques de productivité en temps réel, vos tâches urgentes et recevez des conseils automatisés.

🔔

Rappels en Arrière-plan

Se réduit discrètement dans la barre des tâches (System Tray) avec notifications automatiques avant chaque échéance.

📅

Vue Calendrier Interactive

Visualisez l'ensemble de vos tâches réparties sur le mois avec un code couleur clair d'importance et d'urgence.

🛡️

Double Moteur Qt

Bascule automatiquement entre Qt6 (PySide6) et Qt5 (PyQt5) pour garantir un fonctionnement parfait sur tous les systèmes Windows.

🔒

100% Confidentialité

Données stockées localement dans une base SQLite optimisée. Aucune donnée n'est collectée ni transmise dans le cloud.

🎨

Design Glassmorphic Dark

Interface sombre soignée, typographie moderne et raccourcis clavier intuitifs pour une navigation rapide.

Architecture Technique
