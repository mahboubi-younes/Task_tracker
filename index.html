Gestionnaire de Tâches & Assistant de Productivité

Une application de bureau moderne, fluide et 100% hors-ligne développée avec Python & Qt. Organisez vos priorités, planifiez avec le calendrier interactif et ne manquez aucun rappel grâce au moteur d'arrière-plan.

Fonctionnalités Clés

Pensé pour offrir une expérience utilisateur haut de gamme et réactive

📊

Tableau de Bord KPI

Visualisez instantanément vos statistiques de productivité, vos tâches urgentes et recevez des conseils automatisés selon votre rythme.

🔔

Rappels en Arrière-plan

L'application se réduit discrètement dans la barre des tâches (systray) et déclenche des notifications Windows avant chaque échéance.

📅

Vue Calendrier Interactive

Consultez l'ensemble de vos tâches réparties par jour avec un code couleur clair indiquant la priorité et l'urgence.

🛡️

Compatibilité Étendue

Grâce à notre couche de compatibilité Qt dynamique, l'application s'exécute nativement sous Qt6 (PySide6) ou Qt5 (PyQt5) sous Windows 7.

🔒

100% Confidentialité

Toutes vos tâches et données sont stockées localement dans une base de données SQLite optimisée. Aucune donnée n'est envoyée dans le cloud.

🎨

Interface Dark Glassmorphic

Un design sombre moderne et soigné avec micro-animations, typographie Outfit / Segoe UI et raccourcis clavier intuitifs.

Architecture Technique

Un développement solide reposant sur les meilleures pratiques Python

Langage

Python 3.8 / 3.13

Framework GUI

PyQt5 & PySide6

Base de données

SQLite3 Local

Packaging
